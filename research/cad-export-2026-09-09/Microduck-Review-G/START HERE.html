Microduck v0004
Export for your own CAD and print software / 导出给你自己的软件

This is a small supplement to review v0003, which you already have. It adds nothing new to the design; it packs the same geometry so it opens in one go: one file for the whole robot, one file per material for printing, one zip of every STL, one zip of every real STEP, and the positioned solid assembly as STEP.

这是对你已有的 v0003 评审包的小补充。设计没有变化，只是把同样的几何打包成可以一次打开的文件：整机一个文件、每种材料一个打印文件、全部 STL 一个压缩包、全部真实 STEP 一个压缩包，以及已定位的实体装配 STEP。

  1. READ ME - open in your software.html — Which file to open in which program / 哪个软件打开哪个文件
  2. Microduck - whole robot.3mf — Whole robot, all 70 placed pieces, one file / 整机一个文件
  3. Microduck - assembly.step — Positioned solid parts as one STEP assembly (14 pieces) / 已定位实体装配 STEP
  4. Print all - PLA.3mf — All PLA parts with quantities, for any slicer / 全部 PLA 打印件
  5. Print all - TPU.3mf — All TPU parts / 全部 TPU 打印件
  6. Print all - STL.zip — Every STL in one zip, by material / 全部 STL 压缩包
  7. CAD - STEP.zip — Every real STEP in one zip (10 printed parts + servo reference) / 全部真实 STEP 压缩包
  8. PARTS - formats.csv — Table: part, quantity, material, STEP yes/no / 零件格式表
  9. EXPORT REPORT.json — Verification record: STEP-vs-STL checks, placement checks, hashes / 校验记录

Units mm. Engineering review geometry, not manufacturing approval. Source: review v0003 (zip SHA-256 781bcbb626b81ac0331467e0d77f6511d27626defc1c368079c1ef7b2ec0923f). Real STEP exists for 10 of 30 printed parts; the rest are vendor reference meshes with no solid source and are supplied as STL/3MF only.
