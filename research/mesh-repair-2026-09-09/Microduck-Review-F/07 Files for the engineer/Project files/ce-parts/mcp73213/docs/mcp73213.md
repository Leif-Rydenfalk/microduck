The load-bearing caveat: every limit is conditioned on `VDD= [VREG(Typical)
+ 0.3V] to 12V`, so an 8.40 V pack needs ≥ ~8.7 V in. **5 V USB cannot
charge a 2S pack through this part.** The switch-mode alternative saved as
`docs/alternative-ltc4002-4002f.pdf` (LTC4002-8.4, input `8.9V to 22V`) is a
step-down charger and does not close that gap either.

Standard: none governs. The sheet's thermal figure names a `4-Layer JC51-7
Standard Board` — a test fixture, not a governing standard; no `standard`
ledger row is written.
