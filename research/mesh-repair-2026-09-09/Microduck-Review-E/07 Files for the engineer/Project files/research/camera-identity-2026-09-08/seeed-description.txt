Description
If your project needs multiple lenses with diverse specs, then this camera module will be your ideal choice for your project. It includes an M12 and CS lenses 2-in-1 mount, i.e. the M12 lenses with wide-angle and CS lenses with high image quality&nbsp;can be assembled to this module. Additionally, this module supports both 15&nbsp;PIN&nbsp;and&nbsp;22&nbsp;PIN&nbsp;CSI&nbsp;(Camera&nbsp;Serial&nbsp;Interface) ports. All of which makes the scenario of this camera module much wilder.
IMX&nbsp;219&nbsp;CMOS&nbsp;camera&nbsp;module&nbsp;comes&nbsp;with&nbsp;a Sony&nbsp;4.60mm(Type&nbsp;1/4.)size&nbsp;square&nbsp;pixel&nbsp;array&nbsp;CMOS. Because of its great price-performance ratio and reliability, this popular CMOS sensor is adopted in many fields, such as customized cameras, robotics, security monitoring systems, AI facial recognition, etc.
And now this CMOS sensor has been included in this camera base module, offering 2 types of lens mounts, allowing&nbsp;you&nbsp;to&nbsp;connect&nbsp;to&nbsp;an&nbsp;M12&nbsp;or&nbsp;CS-mount&nbsp;Lens.&nbsp;With&nbsp;a&nbsp;CS to&nbsp;C&nbsp;mount&nbsp;5mm&nbsp;adaptor&nbsp;ring,&nbsp;a&nbsp;C&nbsp;mount&nbsp;lens&nbsp;can&nbsp;also&nbsp;be&nbsp;adapted&nbsp;by&nbsp;this&nbsp;camera&nbsp;module. In the case of multiple wide ranges of lens choices, it can adapt to various M12/C/CS lenses for different scenarios and applications. For instance, a wide-angle lens for a DIY sports camera, or a high-quality lens plus this module for the surveillance system monitoring.

The&nbsp;maximum&nbsp;resolution&nbsp;can&nbsp;output&nbsp;by&nbsp;this&nbsp;module&nbsp;is&nbsp;3280x2464&nbsp;pixels&nbsp;in&nbsp;static,&nbsp;1080p30,720p60&nbsp;and&nbsp;640x480p90&nbsp;in the video, the image &amp; video quality will be ready-to-use for most of the project.
There&nbsp;are&nbsp;2&nbsp;ports&nbsp;supported&nbsp;by&nbsp;this&nbsp;module.&nbsp;which&nbsp;are&nbsp;15&nbsp;PIN&nbsp;and&nbsp;22&nbsp;PIN CSI ports. Which&nbsp;makes&nbsp;it&nbsp;easy&nbsp;to&nbsp;integrate&nbsp;with&nbsp;devices like seeed studio&nbsp;reTerminal, reComputer Series,

FAQ
1. Is this module able to connect to other Raspberry Pi boards apart from Raspberry Pi CM4?
No, this module only supports&nbsp;Raspberry Pi CM4 with the carrier board.
2. Can I attach the C mount lens to this module?
Yes, If with a 5mm adaptor ring, a C-mount lens can be attached to the CS-mount of this module.
3. Is this module able to connect to Jetson nano?
No, this module is connected to the Jetson carrier board.
