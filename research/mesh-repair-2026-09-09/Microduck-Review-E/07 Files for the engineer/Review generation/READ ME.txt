Reproduction tools from ce-cad and Microduck.
Build the source snapshot with python3 -m cecad.reviewpack --project ROOT --mesh ASSEMBLY.json --out NEW_DIR.
The project prepare_review_geometry.py selects the existing yaw-roll repair for this dated review; it preserves source print files and records the repair provenance. It requires NumPy and SciPy.
Browser evidence scripts use ce-cad web/_cdp.mjs and installed Chrome. Run the viewer test before embedding images, then the document test to verify all embedded images offline and produce the PDF.
The purchased-component gallery is populated by add_bought_model_parts and illustrate_bought. Image embedding is a one-time generation step.
Seal only after inspection using python3 -m cecad.reviewpack --out DIRECTORY --seal.
Archived source documentation is historical and may refer to earlier revisions or online services; START HERE.html is the measured offline entry point.
