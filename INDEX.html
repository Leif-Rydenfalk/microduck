Tools — how every document above is regenerated

Nothing in this repository is hand-maintained if a script can own it. Each tool below regenerates its document from the measured data, so a stale number is a bug with a fix rather than an edit.

ScriptWhat it generatesState
tools/gen_comparison.pyBuilds COMPARISON.html from the measured data.present
tools/gen_index.pyBuilds this index, checking every link.present
tools/head_analysis.pyMeasures head conformance from silhouettes.present
tools/md2html.pyConverts the Markdown docs to the shared HTML style.present
sim/mech_dims.pyMeasures every mesh through the FreeCAD kernel.present
sim/stress_matrix.pyThe structural FEA matrix: parts × load cases × materials.present
sim/compare_render.pyPhoto-matched studio renders and joint close-ups.present
sim/assembly_steps_mj.pyCumulative assembly-step renders.present
sim/run_policy.pyRuns Pollen's trained policies on our meshes.present
electronics/gen_ee.pyGenerates the block diagram, schematics and layout.present

Run anything under sim/ or that imports the CAD kernel with ce-cad/bin/cad <script.py> — the system python3 has neither numpy nor PIL.
