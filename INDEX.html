Tools — how every document above is regenerated

Nothing in this repository is hand-maintained if a script can own it. Each tool below regenerates its document from the measured data, so a stale number is a bug with a fix rather than an edit.

ScriptWhat it generatesState
tools/gen_comparison.pyBuilds COMPARISON.html from the measured data.present

tools/gen_test_plan.pyBuilds TEST-PLAN.html from spec/test-plan.json; computes every derived figure (degrees, encoder counts, tilt thresholds, the walk reference read out of out/sim/report.json) rather than carrying it as text, and REFUSES to publish — exiting non-zero having written nothing — on any of 15 self-checks: a gated test missing from the end-of-line checklist, an unresolved source key, an ID-map range that disagrees with the MJCF, an unfilled token. Each was broken on purpose and watched to fire.present
