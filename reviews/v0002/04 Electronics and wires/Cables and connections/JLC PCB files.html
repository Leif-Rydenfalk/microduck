Not ready to order / 暂不可下单

The official HAT audit reports 40 DRC errors and 9 warnings. The replica IMU is explicitly unprototyped. No file has been uploaded to JLCPCB and no order has been placed. 原版HAT记录40项DRC错误和9项警告；复刻IMU尚未打样。本次没有上传或下单。

For a bare PCB quotation the relevant file is the board's Gerber/drill archive. Component assembly additionally needs the BOM and placement/CPL file from the same revision. The large whole-robot review ZIP is not a PCB fabrication archive. 裸板报价需要对应板卡Gerber及钻孔文件；贴片还需要同版本BOM及坐标文件。整机审查ZIP不是制板文件。

Official HAT C1 / 官方HAT C1

The three source files below belong together. Resolve the recorded J4 hole-clearance errors (0.020 mm actual versus 0.200 mm configured), installed-board identity and servo voltage issue first. The placement file includes artwork/fiducial rows; the audit identifies them. Do not silently order these as components or treat this inventory as approval. 三份文件属于同一版本；先核对DRC、实物版本、舵机供电及坐标表中的非器件项目。

Replica IMU / 第三方复刻IMU

The checkout contains an EDA Pro project and drawings, but no exported Gerber archive, assembly BOM CSV or CPL CSV. The README states it has not been prototyped or physically verified. An engineer must review and export a consistent manufacturing set from that project before it can be a quotation upload set. 源码包含嘉立创EDA专业版工程及图纸，但没有已导出的Gerber、贴片BOM或坐标CSV。必须先审查工程并统一导出，不能把另一个IMU工程的ZIP混用。
